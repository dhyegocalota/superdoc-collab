## Adversarial review

The reviewer picks the three claims most likely to be wrong and tries to refute each.

- [x] Claim 1: the prebuilt bundle behaves like the tsx-transpiled worker in every server test — attack: run the server suite with and without `PROJECTION_WORKER_FILE` and diff the pass lists; result: held — evidence: at bc30596, `vitest run` with the global setup gave 41 files passed, 2 skipped, 397 tests passed, 2 skipped in 77.97 s; the same run through a scratch config that copies `vitest.config.ts` with `globalSetup: []` (every boot on the tsx source path) gave 396 passed, 1 failed, 2 skipped in 86.72 s; the per-test status diff of the two JSON reports (399 entries each) differs only in `testing/prebuilt-worker.test.ts` (the variable is unset, as intended); the other 396 statuses are identical.
- [x] Claim 2: the E2E suite has no remaining shared-state hazard under four workers — attack: run with `--workers=8` and `--repeat-each=2`; result: refuted as stated, held for the shipped configuration — evidence: `pnpm test:e2e --workers=8 --repeat-each=2` gave 94 passed, 2 failed in 2.7 min, both failures `selection-summary.spec.ts:76` at line 90 (`readSelectionCalls` expected 5, received 7): `--repeat-each` runs two copies of the same file in different workers, and both move the process-wide selection counter on the fake OpenRouter, the hazard the spec records. It cannot happen under file-level parallelism with one copy per file: `pnpm test:e2e --workers=8` gave 48 passed in 2.4 min. That run logged one `Skipped summarizing topics, the language model is busy`: `LLM_MAX_CONCURRENT_JOBS = 2` is reached at eight workers, and no spec failed on it. Flake hunts with `--repeat-each` stay red on that spec until the counter is per document.
- [x] Claim 3: the matrix filter `./libs/*` runs both libraries — attack: `pnpm --filter "./libs/*" test:unit` output lists `libs/types` and `libs/history`; result: held — evidence: `Scope: 2 of 5 workspace projects`; `libs/types` 3 files, 13 tests passed in 104 ms; `libs/history` 17 files, 82 tests passed in 695 ms.
