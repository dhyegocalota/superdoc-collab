# Credits

**LLM use.** This codebase is developed with Claude Code (Anthropic) driving the harness in this repository. Every pull request is built by developer sub-agents, tested by a separate tester sub-agent with Playwright MCP and reviewed by a reviewer sub-agent; decisions are recorded in ADRs. The product itself calls a model in three places: topic names for a document, one sentence per topic and the sentence for a selection of edits, through the Vercel AI SDK and OpenRouter ([ADR 0006](adr/0006-llm-via-vercel-ai-sdk.md)). Only author names and edit text are sent (names only, no emails), capped at 500 characters per block and 6000 characters per selection prompt, and the prompts treat that text as data, not instructions; without a key the features degrade to a `failed` state instead of failing the page.

**Libraries.**

- SuperDoc editor and SDK (AGPL-3.0); the editor's usage telemetry is disabled, so the page talks to no host but this server and the LLM provider through it
- Hocuspocus server and provider (MIT) and Yjs (MIT) for real-time collaboration
- Better Auth (MIT) for accounts and sessions
- Drizzle ORM (Apache-2.0) over better-sqlite3 (MIT)
- Hono (MIT) for the API
- React (MIT) and Vite (MIT) for the web app, with d3-scale and d3-shape (ISC) for the streamgraph
- Vercel AI SDK and the OpenRouter provider (Apache-2.0)

**Starter code.**

- shadcn/ui components (MIT) copied into the web app
- superpowers skills (MIT, version 6.4.1) vendored into the agent skills
